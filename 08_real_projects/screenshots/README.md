## 🚀 Cách Chụp Screenshot

```bash
# Chạy app
cd projects_app
flutter run -d chrome

# Trong Chrome: F12 → Device toolbar → Chọn device
# Hoặc: Ctrl + Shift + P → "Capture screenshot"
```
