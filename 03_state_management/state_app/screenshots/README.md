# Screenshots

Thư mục này dùng để lưu screenshots của các exercises.

## Cách thêm screenshot

1. Chạy exercise trên Chrome
2. Nhấn F12 để mở DevTools
3. Nhấn Ctrl+Shift+P, gõ "screenshot"
4. Chọn "Capture screenshot" hoặc "Capture full size screenshot"
5. Lưu file vào thư mục này với tên: `exXX_name.png`
