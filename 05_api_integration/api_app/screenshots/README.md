# Screenshots

Thư mục này chứa screenshots của các bài tập trong Phase 5.

## Cách chụp screenshot

1. Chạy app: `flutter run -d chrome`
2. Navigate đến exercise cần chụp
3. Dùng F12 để mở DevTools
4. Click icon device để chọn kích thước màn hình
5. Chụp màn hình với nội dung cần thiết
