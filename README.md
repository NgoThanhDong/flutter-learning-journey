# Flutter Learning Roadmap

This repository documents my journey learning Flutter from scratch to becoming a Senior Mobile Developer.

## 🚀 Roadmap Overview

### [Phase 1: Dart Fundamentals](./01_dart_fundamentals)
- Basic syntax, OOP, Collections, Futures, Streams.
- **Exercises**: 15+ console apps.

### [Phase 2: Flutter Basics](./02_flutter_basics)
- Widgets, Layouts (Row/Column/Stack), State (setState).
- **Projects**: Profile App, Counter, Login UI.

### [Phase 3: State Management Fundamentals](./03_state_management)
- InheritedWidget, Provider, ChangeNotifier.
- **Projects**: Todo App, Theme Switcher.

### [Phase 4: Navigation & Routing](./04_navigation)
- Navigator 1.0 (push/pop), Named Routes, GoRouter.
- **Projects**: Deep Linking Demo.

### [Phase 5: Networking & API](./05_networking)
- HTTP, Dio, JSON Parsing, Error Handling.
- **Projects**: Movie App (API integration).

### [Phase 6: Clean Architecture](./06_clean_architecture)
- SOLID Principles, Dependency Injection, Repository Pattern.
- **Projects**: Notes App (Clean), User Profile CRUD.

### [Phase 7: BLoC Pattern](./07_bloc_pattern)
- **Status**: ✅ Completed
- **Concept**: Event-driven Architecture, Streams, Blocs, Cubits.
- **Key Projects**:
    - **Todo App** (Cubit CRUD)
    - **Weather App** (BLoC API Handling)
    - **Infinite List** (Pagination & Debounce)
    - **Shopping Cart** (Complex State)
    - **User Management** (Architecture & DI)

## 🛠 Tech Stack
- **Language**: Dart
- **Framework**: Flutter (Web based)
- **IDE**: Google IDX / VS Code
- **State Management**: Provider, BLoC/Cubit
- **Architecture**: MVVM, Clean Architecture
